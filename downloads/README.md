On Windows, choose **Extract All**, open the extracted folder, and double-click **Play Thing Ling.cmd**. Keep the launcher window open while playing. No Node.js, Python, or administrator rights are required. The launcher uses Windows PowerShell and your default browser. Its native Windows execution has not yet been tested in this Linux development environment.

The game supports German, Japanese, Spanish, and Mandarin Chinese. Progress is stored in your browser; use **Settings → Export progress** before switching devices, browsers, or between direct-file play and the Windows launcher.

Checksums are in [SHA256SUMS](https://github.com/ItsTheRenaissanceMan/Thing-Ling/blob/main/downloads/SHA256SUMS). The packages include the original game source and third-party license notices. [Project documentation](../README.md) describes the current content, research, and validation limits.
