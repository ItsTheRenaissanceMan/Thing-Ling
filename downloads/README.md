# Thing Ling downloads

## Native Windows game — version 2.0

[**Download Thing-Ling-Windows.zip**](https://github.com/ItsTheRenaissanceMan/Thing-Ling/raw/refs/heads/main/downloads/Thing-Ling-Windows.zip)

Choose **Extract All**, open the extracted **Thing Ling** folder, then double-click **Thing Ling.exe**. This standalone 64-bit Windows 10/11 game includes its maps, models, vocabulary, CJK font and original audio. It needs no browser, server, Node.js, Python, PowerShell, account or internet connection to play. Your graphics driver must support OpenGL 3.3.

Version 2.0 contains a walkable town and 28 enterable interiors, 5,030 placed objects, 36 residents, 12 missions with 100 ordered stages, 239 nouns in four languages, full-sentence challenges, venue jobs, physical supermarket shopping and spaced review. Read the [player manual](../docs/NATIVE_GAME.md) and [native validation record](../docs/NATIVE_VALIDATION.md). Windows execution remains unverified in this Linux build environment.

Progress saves locally, separately for German, Japanese, Spanish and Chinese. Settings can export a backup or import the earlier browser edition's JSON export. Replacing the executable preserves the operating-system save folder. Editable native source is in [the repository's native directory](https://github.com/ItsTheRenaissanceMan/Thing-Ling/tree/main/native); the Windows ZIP is the ready-to-play game, not the complete source checkout.

The browser edition has 13 maps, 471 authored props and 179 words per language. It has no walkable native avatar or native building/job systems. Its Windows launcher uses **Play Thing Ling.cmd**; that is separate from the current native **Thing Ling.exe**. Browser progress is stored in the browser profile. Use its **Settings → Export progress** to move a backup into the native edition.
